# CTSS as a Therapeutic Target for Postoperative Abdominal Wall Hernia

## Project Overview
This repository contains the R scripts and data used in the study titled **"Identifying Potential Drug Targets for Postoperative Abdominal Wall Hernia Using Mendelian Randomization: A Multi-Omics Study"**. The research identifies **Cathepsin S (CTSS)** as a promising therapeutic target for postoperative abdominal wall hernia using Mendelian Randomization (MR), colocalization analysis, and molecular docking.

## Objectives
The primary objective of this study is to determine causal associations between genetic variants and postoperative abdominal wall hernia, using multi-omics data and MR analysis to identify **CTSS** as a druggable gene for therapeutic interventions.
